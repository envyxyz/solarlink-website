# Google Business Profile to-do list for the owner

Do this once per staffed outlet: Lahore, Islamabad, Rawalpindi, Sargodha. Use the approved block in `docs/CITATIONS.md`; do not type details from memory. Nothing here is a decision yet: values marked [client to confirm] wait for you.

## Steps, in order (repeat for each outlet)

1. Check the profile exists and who owns it. On your phone, open Google Maps and search "SolarLink <city>". If a profile shows, tap it. If it says "Claim this business" or "Own this business?", it is not yet yours. Sign in at business.google.com with the one Google account the company will keep. Success: the profile appears in your Business Profile list with "Verified" next to it. Write down the account email in the CITATIONS.md log. If someone else already owns it, request access and note who.
2. Name. Type it exactly as on the shop sign: "SolarLink". No city, no keywords, no tagline. Google edits or suspends listings that add them.
3. Primary category. This is the strongest single choice. Open the category list, and for each candidate hover over or tap it to read Google's own description. Options to check, not a decision: "Solar energy company", "Solar energy equipment supplier", "Solar energy system service". Pick the one whose description matches what the outlet mainly earns from. [client to confirm]
4. Additional categories. Add only categories for things this outlet really does, each a different Google category. Remove vague or wrong ones.
5. Pin. Drag the map pin onto the shop entrance, not the street or the building next door. Zoom in fully. Success: on satellite view the pin sits on the door.
6. Phone. Enter the landline from the approved block as the main number. Add the mobile or WhatsApp number as the second number only if the owner agrees.
7. Hours. Enter the approved hours. If the shop closes for Friday prayer, add the break. Add special hours for holidays and Eid before each one. Never mark the shop open when it is shut.
8. Website link. Use that outlet's page with tracking tags. Lahore: `https://solarlink.com.pk/outlets/lahore/?utm_source=google&utm_medium=organic&utm_campaign=gbp-lahore`. Other cities: change the page and `gbp-<city>` the same way (islamabad, rawalpindi, sargodha). The page must be live before you add the link.
9. Services. Add each real service as a separate item with one plain line: residential solar, commercial solar, industrial solar, agricultural solar, net metering support. Keep only those this outlet does [client to confirm]. No prices unless real and approved.
10. Description. Limit 750 characters. No links, no offers, no claims about years, ratings, certification or "best". Template: "SolarLink is a solar installation company at [address line] in [city]. We install [list the confirmed systems] for [homes, shops, farms, factories]. Visit the shop, call [landline] or message us on WhatsApp for a quote." [client to confirm wording]
11. Photos. Real photos only, taken on a phone: shop front by day and by night, inside, the team (with each person's permission), real installations. Never AI-generated or edited images, never mock-ups, never stock. Add a few every month.
12. Review requests. Ask every customer, the same way, when the job is handed over. Get the direct link: in the profile, tap "Ask for reviews", copy the link. Make a QR code of that link for a standee at the counter, and send the link on WhatsApp the same day. Never pick only happy customers, never offer money or discounts, never write a review for anyone, never ask for five stars. Let customers use their own words.
13. Replies. Reply to every review within a few days. Use the customer's name and the service they mention. For a complaint, say what will happen next and give the outlet's number. No personal details in a reply.
14. Proof before editing name, address or category. Edits can trigger re-verification, sometimes by video of the street, the sign and the inside in one unbroken take. Have ready: a photo of the sign, the company registration [client to confirm], and a utility bill or rent document showing the address.

## Multan and Gilgit

Create a profile only if a staffed office with a real street address exists there and the owner confirms it. Without that, do not create one, and remove any profile that was made by someone else for these cities. A profile with a made-up or empty address gets suspended and can put the other profiles at risk.

## Never do

- Use the same address for two outlets or a virtual office.
- Show the five-star count or any rating on the website unless it is read straight from the profile with the date.
- Let an agency create profiles under its own account; the owner's account must own them.
