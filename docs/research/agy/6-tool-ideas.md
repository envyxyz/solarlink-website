## Part 3: Five Simple 3D Experiences Optimized for Cheap Android Phones

### 1. Interactive Roof Panel Array Snapper
- **Technique:** Ultra-lightweight glTF (<300KB low-poly mesh) using `<model-viewer>` with responsive WebP poster image fallback.
- **Experience:** Shows a canonical Pakistani home (concrete overhead water tank, mumty room, boundary parapet). User taps '+4 Panels' or '-4 Panels' buttons to snap modular solar arrays onto available roof space.
- **Performance Safeguard:** Zero client-side lighting shaders; uses pre-baked ambient occlusion textures. Low-end Android Go phones automatically render the interactive 2D poster with touch hotspots.

### 2. Day-to-Night Living Energy Flow Cutaway
- **Technique:** SVG Isometric illustration with hardware-accelerated CSS 3D matrix transforms.
- **Experience:** Stylized architectural cutaway of a home. An interactive sun slider (6 AM to 11 PM) animates moving power particles flowing from roof panels into the hybrid inverter, charging the lithium battery, and powering the AC.
- **Performance Safeguard:** 100% DOM-based SVG with CSS `transform: translate3d()` and opacity transitions; zero WebGL canvas overhead ensures rock-solid 60fps on Mali and Adreno budget GPUs.

### 3. 360° Hybrid Inverter & Battery Exploded Showcase
- **Technique:** Pre-rendered 36-frame WebP image sequence (~380KB total payload) driven by touch scrub.
- **Experience:** Allows customer to drag their finger horizontally to rotate a wall-mounted hybrid inverter and lithium battery rack 360 degrees. Tapping hot-spots displays close-up callouts of MC4 solar connectors, DC breakers, and LCD touchscreen.
- **Performance Safeguard:** Completely bypasses real-time 3D geometry and shader compilation; browser simply swaps pre-compressed WebP frames on touchmove without frame drops.

### 4. Rooftop Shadow & Water-Tank Obstacle Caster
- **Technique:** CSS 3D Perspective Plane with dynamic CSS SVG drop-shadow filters.
- **Experience:** Homeowner adjusts a simulated slider representing overhead water tank height (4ft to 10ft) and compass orientation to watch shadow contours sweep across potential panel locations from morning to evening.
- **Performance Safeguard:** Renders using native browser CSS 3D perspective (`perspective: 800px`) and SVG path coordinates; runs smoothly without triggering WebGL context creation or battery drain.

### 5. Elevated Galvanized Iron (GI) Structure Customizer
- **Technique:** Layered SVG Isometric engine with procedural CSS transform toggles.
- **Experience:** Demonstrates custom elevated rooftop mounting options (flush L2 structure vs 8-foot elevated custom pipe structure). Users toggle heights to see how an elevated structure keeps the rooftop open for family evening gatherings.
- **Performance Safeguard:** Vector graphics constructed using clean 2.5D isometric geometry; negligible memory footprint (<50KB), zero load latency, and crystal-clear rendering on any mobile screen resolution.
